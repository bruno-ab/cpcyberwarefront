# GM vs jogador — mesa e campanha (26-10-2026)

- **Campanha:** jogador entra só após convite aceito (`memberPlayerIds`). Ficha no roster sozinha não abre campanha para quem não é membro.
- **Criar personagem:** `/campaigns/:id/create-character` (membro ou GM). Hub global `/characters` redireciona para Campanhas. API exige `campaignId`.
- **Mesa:** jogador precisa de ficha própria no roster; erros `roster-required`, `scene-not-available` e `forbidden` têm mensagens em `VttAccessGate`.
- **UI:** `/narrator` e link no menu só para contas que narram (`asGm`). Toolbar GM na mesa continua atrás de `isGm` do socket.
- **API:** `POST /api/gm/assist` exige JWT + narrador da campanha (quando `campaignId` informado).

Demo: `gm@test.local` / `player@test.local` — ver `cpcyberware` seed.
