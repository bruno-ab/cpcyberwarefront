# Mesa P3 — Visão e ambiente (rascunho)

Depende de P2 estável. Walls já existem (`wall:add`); lights stub (`light:set`).

## Escopo

1. LoS: paredes bloqueiam visão por token; fog derivado (não só brush manual).  
2. Portas: segmento de wall com `open/closed`.  
3. Luzes: radius + token vision (normal / IR / night — amarrar a chrome de olhos na ficha).  
4. Objetos interativos: terminal, cofre, câmera, loot → teste ou `breach:start`.  
5. Efeitos de cena: chuva neon, fumaça, apagão, alerta (CSS/canvas + flag na sessão).  
6. Camada GM annotations + drawing tools (público/privado).  

## Nota de custo

Visão dinâmica é o item mais caro; áudio/efeitos/handout→telefone dão mais imersão por hora. Preferir P3.5 áudio paralelo se combate já estiver jogável.

Detalhar intents após P2.1–P2.4.
