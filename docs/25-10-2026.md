### Layout (fix CSS mesa)

- Grid central `minmax(0, 1fr)` + `min-width: 0` no stage/sidebar; mapa com `width: 100%` / `max-width: 100%` no viewport.
- Chat/Dice: flex só no `panelBody` (`bodyClassName`), não no `<section>` — evita colapsar a coluna do mapa.
- Chat/Dice: **não** capar o painel com `max-height` + `overflow: hidden` — o composer (input + rolagem) é `flex-shrink: 0` e precisa de altura natural; log `.chat` rola (`max-height` ~10rem); coluna `.side` (`max-height: 90vh; overflow: auto`) absorve overflow em viewports baixos.

## Auditoria (25-10-2026)

**Veredito:** produto jogável em modo JSON local (VTT + breach maduros); backend compila e 55 testes passam. Front faz `next build`, mas `tsc` acusa ~17 erros em rotas legadas — mascarados por `typescript.ignoreBuildErrors` em `next.config.js`.

**Riscos principais**

- API JSON sem auth em mutações: `campaign.controller.ts` (heat, shop, wiki POST, roster…), `character.controller.ts` (`POST/DELETE :id/cyberware` sem guard; `GET` lista qualquer ficha).
- Wiki GM via query: `GET .../wiki?role=gm` filtra páginas privadas sem JWT (`campaign.controller.ts` ~477).
- Dev footguns: `local-admin.controller.ts` (`POST reseed` + senhas demo), JWT fallback em `auth/constants.ts`, VTT guest por `playerId`/`name` na query se token inválido (`vtt.gateway.ts`).
- VTT: backend devolve `stale` em `baseVersion`; front emite `vtt:intent` sem tratar ack (`table/page.tsx`).
- JSON DB: `writeJsonDb` síncrono, sem lock — corrida se múltiplas instâncias/processos.
- Front: nav com ~18 links (`AppShell.tsx`); home com cards PT hardcoded (`page.tsx`); CSS dual `--cp-*` vs `--colors-*` (`globals.css`).
- Legado: `/maps` iframe Piggyback + erros TS; `react-router-dom` no `package.json` sem uso aparente.
