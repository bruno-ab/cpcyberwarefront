## Mesa VTT `/table` — layout HUD fullscreen

- **Tabuleiro:** ocupa quase 100% da viewport (`boardRoot`); grid/mapa é camada de fundo; painéis são overlays com glassmorphism (`backdrop-filter`, bordas `--cp-cyan` / `--cp-yellow`).

- **Painéis flutuantes (`FloatingHudPanel`):** esquerda = `RunnerPanel` + Celular/Braindance; direita = reações, `CombatHud`, chat/dados, camadas, presença, iniciativa. **Tab** recolhe/expande os dois; preferência em `localStorage` (`cp-vtt-hud-left-collapsed`, `cp-vtt-hud-right-collapsed`).
- **Combate — só move no turno:** toggle **Só move no turno** no painel `CombatHud` (HUD direito, só narrador) → `combat:lock-move`; sincroniza `rules.tokenMoveOnTurnOnly`. Com combate + iniciativa ativos, jogadores não arrastam/nudgam tokens fora do turno; tooltip no token; GM ignora a trava.
- **Velocidade / movimento tático:** ficha e Runner mostram **Velocidade** (`5 + Destreza`, bônus de chrome em ciano). No turno do token selecionado, contador **Movimento restante/max**, highlight neon das células alcançáveis (BFS 8-vizinhos), bloqueio cliente+servidor ao esgotar; **Resetar movimento (R)** → `token:reset-move`. Arrastar e WASD/setas consomem o mesmo orçamento.
- **GM (`GmToolBar`):** barra compacta por categorias (Visão, **Roster / Tokens**, Devices, Alertas, Cena/Mapa) com gaveta — mesmos `vtt:intent` de antes, só UX.
- **Spawn GM (`GmTokenSpawnList`):** só narrador; lista **Personagens** (roster) e **NPCs** (`GET /api/campaigns/:id/npcs`); arrastar para o mapa ou clicar na ficha + clicar na célula (`token:add` com `characterId` / retrato / dono ou `kind: npc` + AR). Personagem já na mesa fica desabilitado. i18n `vtt.gmSpawn`.
- **Hotbar (`CombatHotbar`):** Atirar, Quickhack, Esquivar, Usar item (desabilitado), Passar turno — **ancorada no rodapé** (`bottomChrome`), abaixo do canvas (não flutua sobre tokens).
- **Linha do tempo de iniciativa (`InitiativeTimeline`):** faixa horizontal fora do mapa, turno atual destacado, retratos dos tokens; toggle **Ocultar/Mostrar** persiste em `localStorage` (`cp-vtt-initiative-timeline`).
- **Navegação do mapa (`BoardNavToolbar`):** canto superior direito do canvas — **Selecionar** (V) vs **Mão** (H) para pan; **Space+arrastar** = pan temporário; soltar Space sem arrastar mantém passar turno / delay. Pan usa `mousemove`/`mouseup` na janela (não perde o arraste ao sair do canvas); spawn GM não intercepta clique com Mão/Space/Pan; cabo NET não bloqueia pan no SVG vazio. Com token selecionado, **setas** ou **WASD** deslocam 1 célula (`token:move`, mesmas regras de dono/camada que arrastar; funciona com ferramenta Mão — setas movem token, não câmera; ignorado em inputs/chat).
- **Atalhos GM (edição, `useTableEditHotkeys`):** só narrador; ignorados em `input` / `textarea` / chat. **?** abre legenda (`GmEditShortcutsLegend`).

Intents de delete: `device:unlink`, `device:remove`, `token:remove`, `wall:remove`. Seleção de device/parede no mapa: ferramenta Selecionar + visão Normal (devices); paredes clicáveis com hit-area larga. **Ctrl+D** / duplicar: não implementado (sem intent).
- **Cenas (`SceneBar`):** canto superior direito do canvas, com `right`/`max-width` via `--vtt-scene-dock-*` conforme `boardRoot[data-panels]` (desloca quando o HUD direito está aberto); clique no título **Cenas** recolhe/expande (chip `Cenas · {nome}`); pref `cp-vtt-scenes-collapsed`.
- **GM mapa:** upload BG → intent `map:background` liga camada Background (VIS) na API; slider **Escala BG**; status `bg(off)` se URL existe mas camada oculta. Modo **Cabear NET** — dois cliques ligam nós; clique direito ou Delete na linha corta (`device:unlink`).
- **Media / BG:** `resolveMediaSrc` + `getApiBaseUrl()` apontam `<img>` e fetch para a API (`NEXT_PUBLIC_API_URL` ou `:4444`); `next.config.js` faz **rewrite** de `/api/*` → Nest (evita 404 no :3000). Upload GM mostra toast em falha (413/tamanho) e overlay `bg(erro)` se o `src` não carregar; grid redimensiona pelo pixel size da imagem.
- **Ficha (`/sheet?id=…`):** botão **Foto do runner** — upload `/api/media/upload` + `PATCH /api/characters/:id/portrait`; spawn na mesa já usa `characterImageSrc` → `portraitUrl` no token.
- **NPC (`/npcs/[id]`):** narrador (GM de alguma campanha) vê **Trocar foto do NPC** — mesmo fluxo de upload + `PATCH /api/npcs/:id/portrait`; lista `/npcs` e spawn VTT leem overrides via `GET /api/npcs/portraits` / `image` da campanha e `resolveMediaSrc` / `npcImageSrc`.
- **Visão:** filtros CSS em `boardRoot[data-view=scan|net]`; lógica de gates Kiroshi/NET inalterada (ex-`NightCityBar`).

- Front: nav com ~18 links (`AppShell.tsx`); home com cards PT hardcoded (`page.tsx`); CSS dual `--cp-*` vs `--colors-*` (`globals.css`).
