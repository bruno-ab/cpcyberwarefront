## API local

Crie `.env.local`:

```
NEXT_PUBLIC_API_URL=http://localhost:4444
```

O client em `src/lib/api.ts` usa essa URL em todos os fetches.

```bash
cp .env.local.example .env.local
npm run dev
```

## Chrome — filtro por região do corpo

- `src/data/bodyPartSlots.ts` mapeia cada SVG (`head`, `arm`, `legs`, …) para slots `CyberWareSlot`.
- Clique numa região em `BodyFigure` filtra o ripperdoc: chrome **instalado** na área + catálogo **compatível**.
- Clique de novo na mesma região (ou “Ver tudo”) limpa o filtro.
- Parte selecionada usa fill `#fed33f` (classe `.body-part-selected`).

## Ficha — visual

- `cHeader` usa grid de metadados + tipografia Audiowide/Raleway (sem glitch gigante).
- Abas da ficha: botões HUD ciano/amarelo; inventário em rows, sem símbolo `¤`.
- Aba **Resumo** inclui vitalidade, cards, atributos e habilidades.
- Vitalidade: trilha de quadrados clicáveis + faixas (Saudável→Morto); `data-severity` dispara glitch/scanlines cyberpunk conforme o dano.

## Instalação de chrome

- Após `Comprar e instalar`, redireciona para `/installation?id=&name=` (barra + reboot).
- Ao chegar a 100%, volta para `/cyberware?id=`.

## Breach Protocol (`/breach`)

- Abas por dificuldade: Treino → Rua → Corpo → Arasaka → Blackwall.
- Desafios com grade, buffer, daemons e timer; API em `GET /api/vtt/breach/challenges` e `POST /api/vtt/breach` com `challengeId`.
- Regras CP2077: células únicas + alternância linha/coluna; UI destaca jogadas legais.

### Minigames extras (mesma rota)

- **Puzzle Crash** (`PuzzleCrashGame`): estilo Puzzle Fighter — combine 2×2 da mesma cor em power gems; gem ⚡ destrói a cor adjacente. Velocidades (Lento/Rua/Netrun/Blackwall) + modo com/sem timer.
- **Terminal Jack** (`TerminalTypingGame`): digitar comandos da lore CP em CRT preto/verde + ASCII; erro = vermelho + glitch (−3s).
