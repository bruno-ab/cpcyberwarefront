# Conta — 26-10-2026

## Rota

- **`/account`** — UI em PT (i18n EN), estilo Night City HUD.

## Seções

1. **Identidade** — email, nome, player id via `GET /api/auth/me`.
2. **Alterar senha** — `POST /api/auth/change-password`.
3. **Opções** — toggles locais: motion (`data-motion`), som UI, idioma (`locale` em localStorage), notificações stub (`nc_notify_pref`).
4. **Excluir conta** — confirmação (email ou `DELETAR`) + senha; `DELETE /api/auth/account`; logout após sucesso.

## Nav

Link **Conta** no header só com `access_token` presente (`useIsLoggedIn` + evento `nc-auth-changed`).

## API base

`lib/api.ts` — local `:4444`, produção via `NEXT_PUBLIC_API_URL`.
